# SmartCalc v1.0

Этот проект является частью учебной программы [Школы 21](https://21-school.ru/). В соответствии с заданием была реализована расширенная версия калькулятора на языке C с использованием структурного программирования. В дополнение к базовым арифметическим операциям, таким как сложение/вычитание и умножение/деление, калькулятор может вычислять арифметические выражения, следуя порядку операций, а также некоторые математические функции (синус, косинус, логарифм и т.д.).

Помимо вычисления выражений, калькулятор также поддерживает использование переменной _x_ и построение соответствующей функции. Также имеется встроенный калькулятор для кредитов и депозитов. Логика и графический интерфейс разделены, все модули покрыты тестами. Для визуальной части проекта использован фреймворк Qt.

## Установка и команды

Для установки вам понадобятся следующие утилиты: `gcc`, `make` и `qmake`.

##### Цели Makefile:

- **install**  
  Устанавливает калькулятор в папку сборки и на рабочий стол.

- **uninstall**  
  Удаляет калькулятор.

- **dvi**  
  Открывает документацию проекта.

- **test**  
  Запускает тестирование модулей калькулятора.

- **gcov_report**  
  Генерирует html-отчет, отображающий покрытие всех функций тестами.

## Тесты

- Тесты были написаны с использованием библиотеки [check](https://libcheck.github.io/check/) // отчет о покрытии с использованием [LCOV](https://github.com/linux-test-project/lcov).

- Для запуска тестов используйте команду:
```bash
make test
```

## Технические спецификации

Программа SmartCalc v1.0 должна быть реализована:

- Программа должна быть разработана на языке C стандарта C11 с использованием компилятора gcc. Можно использовать любые дополнительные библиотеки и модули QT.
- Код программы должен находиться в папке src.
- Программа должна собираться с помощью Makefile, который содержит стандартный набор целей для GNU-программ: all, install, uninstall, clean, dvi, dist, test, gcov_report. Директория установки может быть произвольной, кроме директории сборки.
- Программа должна быть разработана согласно принципам структурного программирования.
- При написании кода необходимо следовать стилю Google.
- Подготовить полное покрытие модулей, связанных с вычислением выражений, юнит-тестами с использованием библиотеки Check.
- Реализация GUI на основе любой библиотеки GUI с API для C89/C99/C11
  <br/>Для Linux: GTK+, CEF, Qt
  <br/>Для Mac: GTK+, Nuklear, raygui, microui, libagar, libui, IUP, LCUI, CEF, Qt
- В программу можно вводить как целые числа, так и вещественные числа с точкой. Опционально можно предоставить ввод чисел в экспоненциальной нотации.
- Вычисление должно происходить после завершения ввода вычисляемого выражения и нажатия символа `=`.
- Вычисление произвольных скобочных арифметических выражений в инфиксной нотации.
- Вычисление произвольных скобочных арифметических выражений в инфиксной нотации с подстановкой значения переменной _x_ как числа.
- Построение графика функции, заданной выражением в инфиксной нотации с переменной _x_ (с координатными осями, отметкой используемой шкалы и адаптивной сеткой).
  - Не обязательно предоставлять пользователю возможность изменять масштаб.
- Область определения и область значений функции ограничены как минимум числами от -1000000 до 1000000.
  - Для построения графика функции необходимо дополнительно указать отображаемую область определения и область значений.
- Проверяемая точность дробной части составляет не менее 7 знаков после запятой.
- Пользователи должны иметь возможность вводить до 255 символов.
- Скобочные арифметические выражения в инфиксной нотации должны поддерживать следующие арифметические операции и математические функции:

### Бонус. Калькулятор кредита

Предоставьте специальный режим "калькулятор кредита" (можно взять banki.ru и calcus.ru в качестве примера):

- Ввод: общая сумма кредита, срок, процентная ставка, тип (аннуитетный, дифференцированный)
- Вывод: ежемесячный платеж, переплата по кредиту, общая сумма платежа

### Бонус. Калькулятор депозита

Предоставьте специальный режим "калькулятор доходности депозита" (можно взять banki.ru и calcus.ru в качестве примера):

- Ввод: сумма депозита, срок депозита, процентная ставка, налоговая ставка, периодичность выплат, капитализация процентов, список пополнений, список частичных снятий
- Вывод: начисленные проценты, сумма налога, сумма депозита на конец срока
